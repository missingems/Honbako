Bring the story to your library.

Use the external-source beta, version 0.2.0 build 30. This source includes one original Honbako story, one chapter, and six online pages. No account or password is needed.

Install from the source list

  1. In Honbako, open Settings → Source Lists and add the URL below.
  2. Open Honbako Original Sources and install Honbako Originals. Adding the list alone does not install a source.
  3. Enable Honbako Originals under Included in Search.
  4. Search for Bookshop. Open The Bookshop Between Pages — Online Edition and read Chapter 1.
https://missingems.github.io/Honbako/sources/index.json

Or import the package

Download the package, then choose Settings → Import Source File in Honbako and select the downloaded .aix file.
