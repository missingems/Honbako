Honbako — Support

Start Reading

Open the original tutorial on the first launch. Add your own files or connect a personal library from Settings.

Search

Pull down in the library to search. Search uses the connections you enable. A provider must have readable chapters for a result to appear.

Offline and Notifications

Offline storage and alerts require an active Pro subscription. Downloading also requires source permission. Check the chapter’s progress/error state and retry if needed. Notification permission and iOS background refresh affect alerts.

Subscriptions

Use Restore Purchases or Manage Subscription in Honbako Pro. Apple manages payment and cancellation.

Report a Problem

Please include your app build, device, iOS version, source name, and the steps that failed. Do not send passwords, source tokens, or private server credentials.
